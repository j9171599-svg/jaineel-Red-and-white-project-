## About the Project

The **Pattern Generator and Number Analyzer** is a menu-driven Python program with two main features:

1. **Generate a Pattern** — prints a growing pattern made from asterisks (`*`).
2. **Analyze a Range of Numbers** — identifies whether each number in a selected range is even or odd and calculates the sum of the numbers in that range.

The program also provides an option to exit and displays a message if an invalid menu choice is entered.

## Requirements

- Python 3 installed on your computer.
- A Python editor or IDE, such as IDLE, VS Code, or PyCharm.

No additional Python packages are required.

   ```bash
   python "jaineel python project2 - Copy.py"
   ```

## How to Use

When the program starts, select an option from the menu:

- Enter `1` to generate a star pattern, then enter the number of rows.
- Enter `2` to analyze a number range, then enter the starting and ending numbers.
- Enter `3` to exit the program.

### Example: Analyze a Range

For a range from `1` to `10`, the program reports each number as even or odd and displays the sum:

```text
Number 1 is Odd
Number 2 is Even
Number 3 is Odd
...
Number 10 is Even
Sum of all numbers from 1 to 10 is: 55
```

### Example: Generate a Pattern

For `5` rows, the pattern printed by the supplied program is:

```text
**
***
****
*****
******
```

## Notes

- The range analysis includes both the start and end values.
- The sum is calculated by adding each number in the selected range.
- The star pattern starts with two asterisks on the first row and adds one asterisk per row.
- Enter valid whole numbers when prompted.
